# NOVA — голосовой ИИ-агент для Windows

Nova живёт на вашем ПК и слушает микрофон. Скажите «Нова, привет, открой ютуб», и она выполнит команду: откроет сайт или программу, найдёт файл, запустит игру в Steam, напишет в Telegram, поставит таймер или просто ответит на вопрос голосом.

Приложение написано на Python с интерфейсом на Tkinter. Оно работает с бесплатными облачными моделями, с платными ключами и полностью офлайн через локальную модель.

> Только Windows 10 и 11. Приложение использует WinAPI (ввод с клавиатуры, окна, громкость, реестр).

## Возможности

- **Голосовое управление ПК.** Открыть сайт или программу, ввести текст, нажать клавишу или сочетание, прокрутить страницу, изменить громкость, свернуть окна, заблокировать компьютер, сделать скриншот.
- **Цепочки команд.** «Открой блокнот и набери привет»: Nova открывает программу, ждёт её окно, выводит его вперёд и только потом вводит текст. Если программа не открылась, цепочка останавливается.
- **Steam.** Открыть Steam и библиотеку, запустить установленную игру по названию, переключиться на сохранённый аккаунт.
- **Telegram от вашего аккаунта.** Отправка сообщений через Telegram Desktop по `@username` или по имени контакта. Отправка через бота тоже поддерживается.
- **Быстрые команды без ИИ.** Частые команды распознаются правилами и выполняются мгновенно, без обращения к модели.
- **Диалог с ИИ.** Свободные вопросы уходят в выбранную модель, ответ озвучивается по мере генерации.
- **Совет ИИ.** Несколько моделей отвечают параллельно, главная собирает лучший ответ. Есть режим «гонка» (отвечает самая быстрая) и автоматическое переключение, если одна модель недоступна.
- **Vision.** Модель может смотреть на экран, пересказывать его и кликать по описанию («нажми на кнопку Скачать»). Нужна модель с поддержкой изображений.
- **Память и дела.** Факты о вас, напоминания, таймеры, будильники, список дел, заметки, утренняя сводка.
- **Режимы (сценарии).** «Запомни это как режим работа» сохраняет последние действия, «режим работа» запускает их заново.
- **Чтение текста.** Перевод, пересказ и объяснение выделенного текста или файла (PDF, DOCX, текст).
- **Информация.** Погода, новости, загрузка процессора и памяти, температура, заряд батареи.
- **Интеграции.** Home Assistant, Spotify и YouTube Music, Google Календарь, Telegram-бот.
- **Всегда рядом.** Значок в трее, автозапуск, глобальная горячая клавиша (по умолчанию `Ctrl+Alt+N`).
- **Характеры.** Друг, строгий, весёлый, дворецкий.
- **Безопасность действий.** Выключение, перезагрузка, закрытие окна и тяжёлых программ, стирание памяти выполняются только после вашего «да».

## Установка

### Вариант 1. Установщик (рекомендуется)

1. Скачайте `NovaAgentSetup.exe` со страницы [Releases](../../releases).
2. Запустите его, выберите папку и нажмите **Установить**. Права администратора не нужны.
3. При первом запуске откроется окно «Быстрая настройка».

Подробности об установщике ниже, в разделе [Установщик](#установщик).

### Вариант 2. Без установки

Скачайте `NovaAgent.exe` из Releases и запустите его. Программа работает и из любой папки.

### Вариант 3. Из исходников

Нужен Python 3.8 или новее (при установке отметьте «Add python.exe to PATH»).

```bat
git clone https://github.com/<ваш-аккаунт>/NovaAgent.git
cd NovaAgent
run.bat
```

`run.bat` создаёт виртуальное окружение, ставит зависимости из `requirements.txt` и запускает `main.py`.

## Быстрый старт

В окне «Быстрая настройка» есть два пути.

**Без ключей, офлайн.** Нажмите «Установить всё и запустить». Скачаются распознавание речи Vosk, llama.cpp и локальная модель, включится голос.

**С облачным сервисом.** Выберите провайдера, нажмите «Получить ключ», вставьте ключ и нажмите «Подключить». Vosk поставится сам.

Дальше просто говорите:

```
«Нова, привет, открой ютуб»       ->  «Да, хозяин», открывается YouTube
«Нова» (пауза) «найди рецепт борща»
```

После имени Nova слушает ещё около 8 секунд, повторять имя не нужно. В настройках можно включить режим непрерывного разговора и отключить слово-пробуждение.

| Что нужно | Что сказать |

| Цепочка | «открой блокнот и набери привет мир» |
| Поиск | «найди рецепт борща», «найди котиков в ютубе» |
| Музыка | «включи песню Imagine Dragons», «пауза», «дальше» |
| Громкость | «громкость на 30», «громче», «без звука» |
| Клавиатура | «нажми enter», «скопируй», «вставь», «переключи окно» |
| Ввод пароля | «введи пароль …» (после ввода нажимает Enter) |
| Steam | «открой стим», «открой библиотеку», «запусти доту в стиме», «найди в библиотеке игру Terraria», «зайди в аккаунт Неумный» |
| Telegram | «напиши в телеграм @username привет», «напиши Васе в телеграм привет», «напиши мне в телеграм купить хлеб» |
| Дела | «напомни через 10 минут позвонить», «таймер на 5 минут», «будильник на 7 30», «добавь в список дел купить хлеб» |

| Экран | «посмотри на экран», «нажми на кнопку Скачать» (нужен vision) |

| Файлы | «найди файл отчёт», «перескажи файл отчёт» |

| Управление Nova | «стоп», «тихий режим», «говори», «будь строгим» |
| Совет моделей | «созови совет, почему небо голубое» |

### Steam

- Игра ищется среди **установленных**: Nova читает манифесты Steam. Названия можно говорить по-русски («доту», «контру», «террарию»), список псевдонимов лежит в `nova/apps.py`.
- «Зайди в аккаунт …» переключает Steam на аккаунт, который уже сохранён на этом ПК. Для этого при обычном входе нужно один раз поставить галочку «Запомнить пароль». Если пароль не сохранён, Nova честно скажет об этом. Вводить пароль Steam за вас она не умеет.
- Переключение аккаунта перезапускает Steam.

### Telegram

- Сообщения отправляются из вашего Telegram Desktop. Он должен быть установлен и открыт в вашем аккаунте.
- Для контакта надёжнее всего `@username`. По имени Nova ищет через быстрый поиск Telegram, поэтому имя нужно называть так, как оно записано в контактах (в именительном падеже).
- Если указаны токен бота и chat id (Настройки, Интеграции), команда «напиши мне в телеграм …» отправляет сообщение через бота. Без них текст уходит в «Избранное».

## Модели ИИ

Nova работает с любым OpenAI-совместимым API.

| Провайдер | Стоимость | Заметки |
|---|---|---|
| Groq | бесплатный лимит | самая низкая задержка, лучший выбор для голоса |
| Cerebras | бесплатный лимит | очень быстрый |
| OpenRouter | бесплатные модели | `openrouter/free` сам выбирает рабочую модель, может отвечать медленно |
| Google Gemini | бесплатный тариф | умеет vision |
| Mistral, NVIDIA NIM, GitHub Models, Z.AI | бесплатные тарифы | |
| Anthropic, OpenAI, xAI, DeepSeek | платный ключ | |
| Ollama, LM Studio | локально | нужен запущенный сервер |
| Встроенная llama.cpp | локально, без ключей | модель скачивается из мастера или с вкладки «Локальная ИИ» |
| Свой API | любой | адрес, ключ и модель вручную |

Бесплатные лимиты и список моделей меняются, актуальный список подгружается кнопкой «Список» в настройках. Кнопка «Проверить ИИ» отправляет тестовый запрос и показывает ответ или точную ошибку.

Режим «Лёгкий» урезает историю, контекст и длину ответа для слабых ПК.

## Голос и распознавание речи

**Озвучка:** Edge TTS (бесплатно, много голосов), Fish Audio и ElevenLabs (нужен ключ), Windows SAPI (офлайн). Фразы синтезируются параллельно, пока играет предыдущая, скорость речи регулируется в настройках.

**Распознавание:** Google (бесплатно, онлайн), Groq Whisper, OpenAI Whisper и Vosk (офлайн, подходит для старых ПК).

## Установщик

`NovaAgentSetup.exe` — небольшой графический установщик в стиле самой программы. Он собирается из `installer/installer.py` и содержит внутри `NovaAgent.exe`.

### Что делает установщик

1. Копирует `NovaAgent.exe` в выбранную папку. По умолчанию это `%LOCALAPPDATA%\Programs\NovaAgent`, поэтому **права администратора не нужны**.
2. Копирует самого себя в ту же папку как `NovaAgentSetup.exe`. Он же служит деинсталлятором.
3. По выбору создаёт ярлык на рабочем столе и в меню «Пуск».
4. Регистрирует программу в списке «Установленные приложения» (раздел реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\NovaAgent`, только для текущего пользователя).
5. По выбору запускает Nova после установки.

Опции окна установки: папка (кнопка «Обзор»), ярлык на рабочем столе, пункт в меню «Пуск», запуск после установки.

### Удаление

Через «Параметры, Приложения, Установленные приложения» или запуском:

```bat
NovaAgentSetup.exe --uninstall
```

Удаляются папка программы, оба ярлыка и запись в реестре. **Настройки и данные в `%APPDATA%\NovaAgent` остаются**, чтобы не потерять ключи и память. Если они не нужны, удалите эту папку вручную.

### Обновление

Запустите новый `NovaAgentSetup.exe` и выберите ту же папку: файл `NovaAgent.exe` будет заменён, настройки сохранятся. Перед этим закройте Nova, в том числе значок в трее.

### SmartScreen и антивирусы

Сборки не имеют цифровой подписи, поэтому Windows SmartScreen может показать предупреждение «Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае». Это типичное поведение для неподписанных программ на PyInstaller, некоторые антивирусы тоже могут реагировать на такие сборки. Если вам важна проверяемость, соберите программу сами из исходников (см. ниже).

## Сборка из исходников

Нужны Windows, Python 3.8+ и интернет.

```bat
build.bat
```

Скрипт выполняет шесть шагов:

1. Проверяет наличие Python.
2. Создаёт виртуальное окружение `venv`.
3. Ставит зависимости из `requirements.txt`.
4. Ставит необязательные модули: Vosk (офлайн-распознавание) и llama-cpp-python (локальная модель через DLL).
5. Собирает `NovaAgent.exe` через PyInstaller (один файл, без консоли, с иконкой).
6. Собирает `NovaAgentSetup.exe`, вкладывая в него готовый `NovaAgent.exe`.

Результат появляется в папке `release`:

```
release/
  NovaAgent.exe        сама программа (запускается без установки)
  NovaAgentSetup.exe   установщик и деинсталлятор
```

Иконка создаётся скриптом `assets/make_icon.py`.

## Плагины

Положите `.py`-файл в папку плагинов (Настройки, Интеграции, «Открыть папку плагинов»). Он подхватывается при запуске. Плагин может добавлять голосовые команды (регулярное выражение и функция) и действия, которые ИИ вызывает тегами `[[имя|аргумент]]`. Готовый пример создаётся автоматически в `example_plugin.py`.

```python
import webbrowser


def hello(match, cfg):
    return "Привет из плагина"


def open_site(arg, cfg):
    webbrowser.open("https://" + arg)
    return "Открываю " + arg


COMMANDS = [(r"^скажи привет из плагина$", hello)]
ACTIONS = {"site": open_site}
```

Функция возвращает текст, который Nova произнесёт.

## Где хранятся данные

Всё лежит в `%APPDATA%\NovaAgent`:

| Файл | Содержимое |
|---|---|
| `config.json` | настройки и API-ключи |
| `agent.log`, `crash.log`, `llama.log` | журналы |
| `notes.txt` | заметки |
| `plugins\` | ваши плагины |

Также там хранятся память о вас, напоминания, список дел и режимы. Скачанные локальные модели и llama.cpp ставятся мастером настройки.

## Безопасность и приватность

- **Ключи API хранятся в `config.json` открытым текстом.** Не публикуйте этот файл и не добавляйте его в репозиторий.
- **Облачные сервисы получают ваши данные.** Текст запросов уходит выбранной модели, аудио уходит выбранному движку распознавания (Google, Groq, OpenAI), текст ответов уходит в Edge TTS, Fish Audio или ElevenLabs. Для полной приватности используйте Vosk, локальную модель и Windows SAPI.
- **Не диктуйте важные пароли.** Если используется облачное распознавание, голос и текст пароля проходят через внешний сервис, к тому же распознавание цифр и регистра ненадёжно. Для паролей надёжнее ввод в текстовом поле программы.
- **Vision отправляет скриншот экрана** выбранной модели. По умолчанию он выключен.
- **Плагины выполняют произвольный код Python** с вашими правами. Ставьте только те, которым доверяете.
- **Опасные команды** (выключение, перезагрузка, закрытие окон и программ, стирание памяти) спрашивают подтверждение. Это включено по умолчанию и отключается в настройках.
- Если окно целевой программы запущено от администратора, Windows не позволит обычной Nova вводить в него текст. Запустите Nova тоже от администратора.

## Частые проблемы

**Ассистент говорит «открываю», но ничего не происходит.** Часть команд выполняется правилами без ИИ, остальное модель оформляет специальными тегами. Слабые бесплатные модели иногда забывают теги: тогда Nova делает один повторный запрос, а если не вышло, говорит «Не получилось». Для клика по экрану включите vision. Для надёжности используйте Groq или Gemini.

**ИИ не отвечает.** В настройках нажмите «Проверить ИИ»: кнопка покажет точную ошибку. Смотрите также `%APPDATA%\NovaAgent\agent.log`.

**Nova говорит или отвечает медленно.** Выберите быстрого провайдера (Groq, Cerebras), повысьте скорость речи в настройках, включите режим «Лёгкий». Первый ответ локальной модели всегда медленнее, пока она загружается.

**Не слышит микрофон.** Проверьте выбранное устройство в настройках и разрешение на доступ к микрофону в Windows.

**Программа не запускается.** Причина записывается в `%APPDATA%\NovaAgent\crash.log`.

**Steam не переключает аккаунт.** Для аккаунта должен быть сохранён пароль (галочка «Запомнить пароль» при входе). Подробнее в разделе про Steam выше.

```
NovaAgent/
  main.py              точка входа
  run.bat              запуск из исходников
  build.bat            сборка exe и установщика
  requirements.txt     зависимости
  assets/              иконка и скрипт её создания
  installer/
    installer.py       графический установщик и деинсталлятор
  nova/
    agent.py           ядро: очередь задач, разбор тегов, цепочки команд

    council.py         совет моделей, гонка, переключение при сбое
    stt.py             распознавание речи
    tts.py             озвучка
    memory.py          память, напоминания, список дел, режимы

    plugins.py         загрузка плагинов
    wizard.py          мастер быстрой настройки
    localsetup.py      установка llama.cpp, моделей и Vosk
    ui.py, tray.py, hotkey.py   интерфейс, значок в трее, горячая клавиша
```
