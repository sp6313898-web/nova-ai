NOVA - голосовой ИИ-агент (Python, Tkinter, чёрный интерфейс)

СБОРКА
1. Установите Python 3.8 или новее (python.org), отметьте "Add python.exe to PATH".
2. Запустите build.bat (нужен интернет). В папке release появятся:
   NovaAgentSetup.exe - установщик (галочка ярлыка на рабочий стол, меню Пуск, удаление)
   NovaAgent.exe      - сама программа (можно запускать без установки)
Для запуска без сборки: run.bat

БЫСТРЫЙ СТАРТ (после установки)
При первом запуске откроется окно "Быстрая настройка". Нажмите "Установить всё и запустить":
скачаются распознавание речи Vosk, локальный ИИ (llama.cpp + модель) и включится голос. Ключи не нужны.
Или выберите облачный сервис, нажмите "Получить ключ", вставьте ключ и нажмите "Подключить"
(Vosk поставится сам). Дальше просто говорите:
  "Нова, привет, открой ютуб"  ->  "Да, хозяин" и YouTube открывается
  "Нова" (пауза) "найди рецепт борща" - после имени ассистент слушает ещё около 8 секунд без повторения имени.
Кнопка "Настройка" открывает мастер снова, внутри есть "Расширенные настройки".

ПЕРВЫЙ ЗАПУСК
Настройки - Модель: выберите провайдера, нажмите "Получить ключ" (откроется страница, ключ бесплатный),
вставьте ключ. Список моделей в поле Модель подставляется сам, кнопка Список подгружает актуальные.
Бесплатные облачные API (на ноябрь 2026, лимиты меняются):
  OpenRouter  - openrouter/free сам выбирает работающую бесплатную модель, 50 запросов в день
  Groq        - gpt-oss, самый быстрый, ~1000 запросов в день, лучший для голоса
  Gemini      - gemini-2.5-flash, умеет vision
  Cerebras    - ~1 млн токенов в день
  Mistral, NVIDIA NIM, GitHub Models, Z.AI (GLM-4.7-Flash, GLM-4.6V-Flash с vision)
Если выбранная модель OpenRouter перестала работать, программа сама переключается на openrouter/free.

ВОЗМОЖНОСТИ (говорите после "Нова,")
Управление ПК:   набери привет мир / нажми enter / скопируй / вставь / прокрути вниз / переключи окно /
                 громкость на 30 / сделай скриншот / найди файл отчёт / нажми на кнопку Скачать (нужен vision)
Цепочки команд:  открой телеграм и введи пароль 1234 / открой блокнот и набери привет. Приложение сначала
                 открывается, окно выводится на передний план, и только потом идёт ввод. Если приложение не
                 открылось, цепочка останавливается и пароль никуда не вводится.
Steam:           открой стим / открой библиотеку / запусти доту в стиме / найди в библиотеке игру Terraria /
                 зайди в аккаунт Неумный (переключает на сохранённый аккаунт, пароль в Steam должен быть
                 сохранён галочкой Запомнить пароль; иначе ассистент честно скажет, что нужен ручной вход)
Telegram:        напиши в телеграм @username привет / напиши Васе в телеграм привет / напиши мне в телеграм текст
                 (пишет из вашего Telegram Desktop; токен бота нужен только для отправки через бота)
Память и дела:   запомни что я люблю джаз / что ты помнишь обо мне / напомни через 10 минут позвонить /
                 поставь таймер на 5 минут / будильник на 7 30 / добавь в список дел купить хлеб / что в списке дел
Режимы:          запомни это как режим работа (запоминает последние действия) / режим работа /
                 создай режим игры открой стим открой дискорд
Чтение:          переведи выделенное / перескажи выделенное / перескажи файл отчёт / прочитай экран (vision)
Информация:      погода / новости / утренняя сводка / что грузит процессор / температура / заряд батареи
Безопасность:    выключить, перезагрузить, закрыть окно, закрыть тяжёлые программы, стереть память -
                 сначала спрашивает подтверждение (да или нет)
Характер:        Настройки - Поведение (друг, строгий, весёлый, дворецкий), обращение, тихий режим
Всегда рядом:    значок в трее, автозапуск, горячая клавиша (по умолчанию ctrl+alt+n)
Интеграции:      Telegram (токен бота и chat id), Home Assistant, Spotify/YouTube Music, календарь Google
Плагины:         Настройки - Интеграции - Открыть папку плагинов, там пример example_plugin.py

СОВЕТ ИИ (в одном ассистенте умы многих моделей)
Настройки - Совет ИИ: отметьте модели и вставьте ключи (Groq, Gemini, OpenRouter, Cerebras бесплатны;
Claude, GPT, Grok - платные ключи). Режимы: Авто (сложные вопросы обсуждают все модели, а главная модель
собирает лучший ответ), Всегда, Гонка (отвечает самая быстрая). Если одна модель недоступна, ассистент
сам переключается на другую. Фраза "созови совет ..." включает совет для одного вопроса.

ЕСЛИ АССИСТЕНТ ГОВОРИТ "ОТКРЫВАЮ", НО НИЧЕГО НЕ ДЕЛАЕТ
Часть команд работает без ИИ (быстро и надёжно), остальное выполняет модель через теги. Слабые бесплатные
модели иногда забывают теги: программа тогда делает один повторный запрос и, если не вышло, сама говорит
"Не получилось". Для клика по экрану и выбора аккаунта в окнах включите vision (Настройки - Модель).
Если окно приложения запущено от имени администратора, Windows не даёт вводить в него текст: запускайте
Nova тоже от администратора.

ЕСЛИ ИИ НЕ ОТВЕЧАЕТ
В Настройках внизу слева кнопка Проверить ИИ: она сохранит настройки, отправит тестовый запрос и покажет
ответ или точную ошибку. Логи: %APPDATA%\NovaAgent\agent.log и llama.log.

ЛОКАЛЬНАЯ ИИ (без интернета и ключей)
Настройки - Локальная ИИ - выберите модель - "Скачать и настроить". Программа сама скачает llama.cpp
и модель с Hugging Face, пропишет пути и включит локальную ИИ. Модели с пометкой VISION умеют видеть экран.
Кнопки Запустить и Остановить на той же вкладке запускают и гасят модель вручную.
Для старых ПК: Qwen2.5 1.5B, Llama 3.2 1B или Gemma 3 1B. Первый ответ медленнее, пока модель грузится.
Вручную: укажите llama-server.exe (или llama.dll) и файл .gguf. Ollama и LM Studio тоже поддерживаются.

ГОЛОС (Настройки - Голос)
Edge TTS - бесплатно, сотни голосов, без ключа.
Fish Audio / ElevenLabs - вставьте ключ, нажмите "Загрузить / найти голоса" (в поле слева можно искать по названию).
Windows SAPI - офлайн, самый лёгкий для старых ПК.

VISION
Включите "Vision" на вкладке Модель и скажите "посмотри на экран". Облако: модель с поддержкой картинок
(Gemini, Z.AI glm-4.6v-flash, OpenRouter openrouter/free). Локально: vision-модель .gguf + файл mmproj.

РАСПОЗНАВАНИЕ РЕЧИ
Google (онлайн, бесплатно), Groq Whisper (ключ Groq), Vosk (офлайн; скачайте маленькую модель
alphacephei.com/vosk/models и укажите папку). Кнопка "Слушать" включает постоянное прослушивание.

КОМАНДЫ БЕЗ ЗАДЕРЖКИ (не идут в ИИ)
открой ютуб / гугл / телеграм / дискорд / блокнот ..., найди X, найди X на ютубе, пауза, дальше, громче,
тише, без звука, сверни все окна, который час, заблокируй компьютер, запомни X, стоп, посмотри на экран.
Остальное решает ИИ и сам запускает действия (открыть сайт, программу, поиск, медиа).
Свои программы: Настройки - Система, строки вида  название=C:\путь\программа.exe

ИНТЕРФЕЙС
Живой шар вверху реагирует на состояние: дышит в ожидании, пульсирует от громкости вашего голоса,
крутит дугу пока ИИ думает, играет волной пока говорит. Сообщения плавно проявляются, кнопки и окна
плавно меняют цвет и появляются. Иконка: assets\icon.ico (пересоздать: python assets\make_icon.py).
Анимации отключаются в Настройки - Система - Лёгкий режим.

СТАРЫЕ ПРОЦЕССОРЫ (от Core 2)
Включите "Лёгкий режим" (отключает анимации), выберите Windows SAPI или Edge TTS, распознавание Google или Vosk.
Облачная модель даёт минимальную нагрузку на CPU. Ответ озвучивается по предложениям по мере генерации.

Данные: %APPDATA%\NovaAgent\config.json (ключи хранятся там открытым текстом).
Ошибка запуска пишется в %APPDATA%\NovaAgent\crash.log
